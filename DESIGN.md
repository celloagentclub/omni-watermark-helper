# Omni 去水印助手 UI Design Brief

## Target Audience

Paid creator-group members who generate short Omni/Gemini videos and need a
reliable batch-cleaning desktop tool without technical setup.

## Licensing Model

- Product name: Omni 去水印助手.
- License type: permanent license.
- Binding rule: one activation code binds to one machine code.
- Distribution: activation codes are issued manually through private messages.
- Contact flow: the activation page shows a QR entry for adding the seller.
- Offline use: a valid perpetual license remains available on its bound machine.

## Job To Be Done

Import multiple 10-second videos, choose an output quality tier, run batch
watermark removal locally, and export cleaned files with predictable status.

## Visual Direction

Quiet professional desktop utility. The interface should feel licensed,
trustworthy, and efficient rather than playful or promotional.

Primary direction: high-tech graphite processing console with native desktop
workbench discipline.

## Palette Roles

- Workspace base: graphite-black for focused desktop operation.
- Ink: cool near-white for command labels and dense data.
- Panel surface: layered dark metal with muted separators.
- Action: orange signal accent for primary progress and active controls.
- Warning: amber for invalid video length or activation attention.
- Success: calibrated green for completed jobs.

## Typography

- UI font: system UI stack for native desktop familiarity.
- Scale: compact operational hierarchy.
- Page title: 24-28px.
- Section titles: 13-15px, semibold.
- Queue data: 12-14px.
- Button text: 12-14px.

## Component Language

- Radius: 6-8px maximum.
- Borders: 1px solid, low contrast, near-flat elevation.
- Density: desktop app density, scan-friendly.
- Layout: three-zone workbench.
  - Left: intake and license.
  - Center: batch queue.
  - Right: output profile and preview.
- Controls: segmented quality selector, compact icon buttons, progress bars,
  toggles for binary settings, disclosure for advanced controls.

## Motion Strategy

- Reveal: uploaded items enter with slight opacity/translate.
- Progress: linear progress bars, no bounce.
- Focus: active tier and selected queue row receive restrained border change.
- Settle: completion state fades into green status.

## Hard Don'ts

- No marketing hero page.
- No decorative gradient blobs/orbs.
- No glassmorphism.
- No card-inside-card nesting.
- No oversized typography inside operational panels.
- No purple-blue cyber palette.
- No visible tutorial paragraphs in the app surface.

## QA Focus

- Text must not overflow at desktop or narrow widths.
- Upload queue must remain usable with many files.
- Primary action must stay visible.
- The default 1220x820 desktop window must not require page scrolling.
- Queue rows must prioritize readable filenames over repeated metadata.
- Preview surfaces must show real selected media or an explicit empty state.
- Failed jobs must expose a direct retry action and preserve the error reason.
- First viewport must immediately communicate batch processing, one-machine
  licensing, and the activation/contact path.
- Console must be clean in browser validation.
